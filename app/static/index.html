Enterprise Production Recommendation Matrix

Deployment Strategy
RECOMMENDED FOR IVR & STUDIO

Deploy Prisma v3.0 when:

  • High audio fidelity is present (Clean web/app audio, standard telephony).
  • Conversational Hinglish & code-mixed Hindi-English dialogues are dominant (achieved 31.60% WER vs 39.96% for v2.5).
  • Highest syntactic transcription accuracy and lowest Character Error Rate (CER 2.45%) are mission-critical.
RECOMMENDED FOR HIGH-NOISE TELEPHONY

Deploy Prisma v2.5 when:

  • Audio arrives from noisy mobile street channels, factory floors, or moving vehicles (0 dB to 10 dB SNR).
  • Low word omission and resistance to background chatter degradation are required (18.92% vs 25.82% WER at 0 dB SNR).
  • Sub-200ms P50 response latency is strictly constrained on low-bandwidth edges.

Dead Man's Switch & Rate Limiter Safeguards

1. Cross-Process File Lock

Uses calllens/call_counter.py with portalocker to guarantee that separate script processes (G1, G2, G3) share ONE persistent counter that halts when reaching 434 attempts.

2. Concurrency Rate Limiter

Token bucket enforcing a maximum of 2 concurrent network requests to prevent server 429 throttling and connection exhaustion.

3. Automatic Header Redaction

All logging and trace output automatically scrubs token, api-key, and authorization headers to guarantee zero credential leakage.

Scientific Methodology & Provenance Architecture

Comprehensive technical documentation on experimental design, dataset sources, text normalization, and statistical rigor.

1. Benchmark Datasets

FLEURS Hindi (hi-IN) Read Speech

30 standardized speech clips under CC BY 4.0 license. Durations ≤ 28 seconds, sampled at 16 kHz. Represents clean native Hindi pronunciation across varied speakers.

BFSI Banking Hinglish Dialogues

10 conversational debt collection and payment reminder scenarios voiced via Gnani Timbre v2.5 (Pranav, hi-IN), testing complex number words, dates, and code-mixed vocabulary.

Noise & Silence Hallucination Suite

20 five-second clips (10 seeded white Gaussian noise, 10 digital silence) to verify that neither model outputs phantom words on non-speech inputs.

2. Statistical Rigor: Clip-Level Bootstrap Resampling

Standard aggregate WER averages obscure clip-level variance. CallLens computes 95% two-sided confidence intervals using non-parametric bootstrap resampling:

  • Resamples: 1,000 bootstrap iterations per condition and model.
  • Random Seed: Fixed seed 0 for deterministic reproducibility.
  • Confidence Interval: Percentile method [2.5th percentile, 97.5th percentile].

3. Provenance Isolation Guarantee

Synthetic mock demonstration data and genuine live provider results are strictly isolated at the database level via the provenance column in SQLite (../calllens-data/benchmark.db). Live aggregations and replay modes strictly filter by provenance = 'live', guaranteeing zero mock data mixing.
